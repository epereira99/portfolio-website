# Memory painting prompts (Nano Banana)

## How to use

For each memory, start a **new chat** and upload, in this order:

1. The reference photo(s) listed for it, from `art/references/`.
2. **`art/memories/nau.png` as the style reference**, so every memory matches the ship that's already on the site.

Paste the prompt. Save the result as `art/memories/<file name>.png`, then run `npm run gen:memories`.

If a result drifts, use these follow-ups in the same chat:
- **Text or a watermark appears:** *"Remove all text, signs, logos and watermarks."*
- **People appear:** *"Remove all people and vehicles."*
- **Too detailed or photographic:** *"Looser brush strokes, less detail, softer, more like a memory."*
- **Faded or blurred edges:** *"Paint the whole frame edge to edge: no vignette, no fading, no blur at the edges."* (The site adds its own fade.)
- **Daylight creeps back:** *"Make it night: deep navy starry sky, warm lit windows and street lamps."*
